# edge_delam_rcj.txt - 재결합 접합 가장자리 박리 (rcj 대상, 8x8)
#
# 용도 : 상·하부 서브셀 **사이**의 수직 접촉이 가장자리에서 나빠진 상황.
#        라미네이션 압력이 가장자리로 갈수록 빠지거나, 중간층(ITO/nc-SiOx)이
#        모서리에서 들뜬 경우. 겉보기 증상은 FF 하락인데 션트도 직렬저항도
#        아니어서 원인을 찾기 어려운 그것.
# 대상 : rcj  (재결합접합 수직 접촉 비저항 Rc_junction 배율, v28.66).
#
# ⚠⚠ rc와 **다른 대상이다.** 단위가 둘 다 Ω·cm²라 헷갈리기 쉽다.
#     rc  = 전극(금속) ↔ 반도체 접촉        - 전면 그리드, 강성 조립(B 계층)
#     rcj = 상부 서브셀 ↔ 하부 서브셀 접촉  - 재결합 접합, 노드 잔차(A 계층)
#   서로 바꿔 걸면 오류 없이 조용히 다른 물리를 계산한다.
#
# ⚠⚠ 값의 방향이 직관과 반대다 (rc·rsh와 같은 함정).
#   이 맵은 접촉 **비저항**을 곱한다.
#     1.00 = 기준 그대로       -> 정상 접합 (중앙)
#     4.00 = Rc_j가 4배        -> **나쁜 곳** (박리된 가장자리)
#   "접합이 좋으니 값을 크게"라고 쓰면 정반대가 된다.
#
# ⚠ tandem 모드에서만 의미가 있다. single 모드에는 중간층이 없으므로
#   맵을 붙여도 잔차에 나타나지 않는다.
#
