# local_shunt_rsh.txt - 국부 션트(누설) 분포 (rsh 대상, 8x8)
#
# 용도 : 스크라이빙 잔여물, 금속 침투, 핀홀처럼 셀 한 자리에서만 누설이 큰 상황.
#        EL 이미지에서 한 점만 어둡게 나오고 저전압 FF가 무너지는 그것.
# 대상 : rsh  (션트 저항 배율). 다른 대상에 걸지 말 것 - 의미가 뒤집힌다.
#
# ⚠⚠ 값의 방향이 직관과 반대다.
#   이 맵은 션트 **저항 Rsh**를 곱한다(누설 컨덕턴스 1/Rsh를 나눈다).
#     0.15 = Rsh가 기준의 15%  -> 누설 약 6.7배  -> **나쁜 곳** (션트 지점)
#     1.00 = 기준 그대로        -> 깨끗한 곳
#   "션트가 심하니 값을 크게"라고 쓰면 정반대가 된다. rc와 같은 함정이다.
#
# ⚠⚠ Griddler와 곱셈 방향이 **반대**다.
#   Griddler는 shunt를 **컨덕턴스 G_shunt [S/cm²]**로 두고 GEDO는
#   **저항 Rsh [Ω·cm²]**로 둔다. Griddler용 맵을 그대로 가져오면 역효과가 난다 -
#   역수를 취할 것. docs/spatial_map_convention.md §7.
#
# ⚠ 8x8 격자로는 "지름 1 mm 핀홀"을 표현할 수 없다. 노드 사이가 쌍선형 보간이라
#   국부 션트가 셀 폭의 1/7 정도로 번진다. 실제 크기에 맞추려면 격자를 키울 것.
#
