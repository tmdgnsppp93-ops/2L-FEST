#
# 용도 : 레이저 스크라이빙/절단면 손상, 가장자리 패시베이션 열화처럼 셀 둘레의
#        재결합이 안쪽보다 큰 상황. PL/EL 이미지에서 테두리가 어둡게 나오는 그것.
# 대상 : j01 (n=1 다이오드 포화전류 배율). 같은 형상을 j02에 걸어도 된다 -
#        j02는 공핍층(n=2) 재결합이라 저전압 쪽 FF에 더 크게 작용한다.
#
# 값   : 1.0 = 기준. 클수록 재결합이 크다(= 나쁘다).
#          1.00  셀 안쪽 - 손상 없음
#          1.10  바깥에서 두 번째 줄
#          2.50  변의 한가운데 (바깥 줄)
#          4.00  네 모서리 - 두 변의 손상이 겹치는 곳
#        Voc가 먼저 떨어지고 FF가 따라 떨어지는 것이 정상이다.
#
# ⚠ 8x8 격자로는 "폭 1 mm의 가장자리"를 그대로 표현할 수 없다.
#   노드 사이는 쌍선형 보간이라, 바깥 줄의 큰 값이 안쪽으로 셀 폭의 약 1/7까지
#   번진다. 실제 손상 폭에 맞추려면 격자를 키울 것 (예: 20 mm 셀에서 1 mm 띠를
#   원하면 한 칸이 1 mm가 되도록 21x21).
#
