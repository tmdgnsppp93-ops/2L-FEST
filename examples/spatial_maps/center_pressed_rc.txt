# center_pressed_rc.txt - 중앙이 잘 눌린 접촉 압력 분포 (rc 대상, 8x8)
#
# 용도 : 스크린 프린팅/라미네이션에서 셀 중앙이 강하게 눌리고 가장자리로 갈수록
#        압력이 빠지는 상황. 실측 압력 필름(Fuji Prescale 등) 패턴의 대용.
# 대상 : rc  (접촉 비저항 배율). 다른 대상에 걸지 말 것 - 의미가 뒤집힌다.
#
# ⚠⚠ 값의 방향이 직관과 반대다.
#   이 맵은 접촉 **저항**을 곱한다(컨덕턴스를 나눈다).
#     0.58 = 접촉저항이 기준의 58%  -> 잘 눌린 곳 (중앙)
#     2.00 = 접촉저항이 기준의 2배   -> 덜 눌린 곳 (네 모서리)
#   "잘 눌렸으니 값을 크게"라고 쓰면 정반대 결과가 나온다.
#
# ⚠ rc 맵은 **금속 노드에서만** 효과가 있다. 패시베이션 영역에는 접촉 자체가
#   없으므로 그 칸의 값은 결과에 반영되지 않는다.
#
# 규약: 첫 데이터 줄 = 셀의 아래쪽(y=0). 중앙 대칭이라 위아래를 뒤집어도 같다.
